# archival-video-metadata

Tools for automated extraction of technical metadata from digital video files for archival description.

## Python scripts

The Python scripts are located in the `python/` directory. The only third-party Python dependency required by the current scripts is **PyAV** (`av`); the remaining imported modules belong to the Python standard library.

For installation and execution on Windows, see [WINDOWS_SETUP.md](WINDOWS_SETUP.md).

Quick installation:

```powershell
py -m pip install -r requirements.txt
```

Recommended script:

```powershell
py python\archival_video_metadata.py
```
