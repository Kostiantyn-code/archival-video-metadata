# archival-video-metadata

Інструментарій для автоматизованого формування технічних метаданих цифрових відеодокументів під час підготовки архівних описів.

Репозитарій містить основну реалізацію мовою **Python** та попередню реалізацію мовою **PowerShell**. PowerShell-сценарій збережено для демонстрації еволюції підходу та порівняння результатів. Для практичного використання рекомендовано Python-версію.

## Основна реалізація

Основний сценарій:

`python/archival_video_metadata.py`

Він рекурсивно опрацьовує відеофайли та формує такі технічні метадані:

- назва файла або відносний шлях;
- роздільна здатність;
- тривалість;
- розмір файла;
- SHA-256.

Підтримуються файли `.mp4`, `.mov`, `.avi`, `.mpg`.

Python-версія використовує бібліотеку **PyAV**. Окреме встановлення **FFmpeg** або `ffprobe` для стандартного запуску Python-версії у Windows не потрібне.

## Запуск у Windows

1. Завантажте репозиторій через **Code → Download ZIP** та розпакуйте його.
2. Установіть Python 3.10 або новіший.
3. Помістіть відеофайли до каталогу `input`.
4. Запустіть `run.bat`.

Під час першого запуску `run.bat` створює локальне середовище `.venv` та встановлює залежність PyAV із `requirements.txt`. Для цього потрібне підключення до інтернету.

Результати кожного запуску зберігаються в окремому каталозі:

```text
output/run_ДАТА_ЧАС/metadata.csv
```

Якщо окремі файли не вдалося опрацювати, у тому самому каталозі створюється `errors.txt`.

## Використання зовнішнього каталогу

Копіювати відеофайли до `input` не обов'язково. Вхідний каталог можна вказати параметром:

```powershell
.\run.bat --input "D:\Відео архіву"
```

За потреби можна окремо визначити каталог результатів:

```powershell
.\run.bat --input "D:\Відео архіву" --output "D:\Звіти"
```

Параметр `--relative-paths` записує в перший стовпець CSV шлях відносно вхідного каталогу замість лише назви файла:

```powershell
.\run.bat --input "D:\Відео архіву" --relative-paths
```

## Прямий запуск Python

Залежність можна встановити окремо:

```text
python -m pip install --only-binary=:all: -r requirements.txt
```

Запуск основного сценарію:

```text
python python/archival_video_metadata.py
```

Доступні параметри:

```text
python python/archival_video_metadata.py --help
```

## Формат результату

CSV містить поля в такому порядку:

1. назва файла або відносний шлях;
2. роздільна здатність;
3. тривалість;
4. розмір файла;
5. SHA-256.

Приклад:

```text
0001.mp4;1920x1080;03:27;31,30;A1B2C3D4...
```

Як роздільник полів використовується крапка з комою (`;`), а для дробової частини розміру файла — десяткова кома. CSV записується у **UTF-8 with BOM**, що забезпечує коректне відкриття українського тексту в Microsoft Excel за типових регіональних налаштувань.

Основний Python-сценарій округлює тривалість до найближчої цілої секунди та для записів понад одну годину використовує формат `HH:MM:SS`.

## Сумісна Python-реалізація

`python/powershell_compatible.py` відтворює ключові особливості формату попередньої PowerShell-реалізації. Вона збережена для порівняння результатів і не є рекомендованим варіантом для нової обробки.

## Попередня PowerShell-реалізація

`powershell/resolution3.ps1` — рання версія інструментарію, збережена в репозитарії для демонстрації розвитку підходу від PowerShell до Python.

На відміну від основної Python-версії, PowerShell-сценарій безпосередньо використовує `ffprobe.exe`, тому **FFmpeg потрібен лише для цієї попередньої реалізації**. Сценарій також містить жорстко задані шляхи, які перед запуском необхідно змінити відповідно до локальної конфігурації.

## Перевірка
