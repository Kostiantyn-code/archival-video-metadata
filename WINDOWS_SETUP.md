# Запуск Python-сценаріїв у Windows

Ця інструкція стосується Python-сценаріїв у каталозі `python/`.

## 1. Встановлення Python

Встановіть актуальну версію Python для Windows. Для поточної версії PyAV рекомендується Python 3.10 або новіший.

Після встановлення перевірте доступність Python у командному рядку або PowerShell:

```powershell
py --version
```

Якщо команда `py` недоступна, перевірте:

```powershell
python --version
```

## 2. Необхідні бібліотеки

Python-сценарії використовують такі модулі стандартної бібліотеки Python:

- `csv`
- `hashlib`
- `math`
- `pathlib`

Вони встановлюються разом із Python і не потребують окремого встановлення.

Єдина додаткова Python-бібліотека, необхідна для поточних сценаріїв, — **PyAV** (`av`). Вона використовується для читання технічних характеристик мультимедійних файлів.

Встановити залежності можна командою:

```powershell
py -m pip install -r requirements.txt
```

або безпосередньо:

```powershell
py -m pip install av
```

За потреби перед цим можна оновити `pip`:

```powershell
py -m pip install --upgrade pip
```

Офіційні бінарні пакети PyAV для Windows постачаються пов'язаними з бібліотеками FFmpeg, тому для звичайного встановлення PyAV через `pip` окремо встановлювати FFmpeg для Python-сценаріїв не потрібно. Окреме встановлення FFmpeg може знадобитися лише для спеціальних конфігурацій або складання PyAV із вихідного коду.

## 3. Перевірка встановлення PyAV

```powershell
py -c "import av; print(av.__version__)"
```

Якщо команда виводить номер версії без повідомлення про помилку, бібліотека встановлена коректно.

## 4. Налаштування шляхів у сценарії

Перед запуском відкрийте потрібний файл у каталозі `python/` і змініть шляхи до вхідної директорії та вихідних файлів відповідно до вашої системи.

У рекомендованому сценарії `python/archival_video_metadata.py` це параметри:

```python
INPUT_DIR = Path(r"D:\temp\2026")
OUTPUT_FILE = Path(r"D:\temp\resolution-python-recommended.csv")
ERROR_FILE = Path(r"D:\temp\resolution-python-errors.txt")
```

## 5. Запуск із Windows

Перейдіть у каталог репозитарію та виконайте:

```powershell
py python\archival_video_metadata.py
```

Для сумісної з первинною PowerShell-реалізацією версії:

```powershell
py python\powershell_compatible.py
```

Використання IDE не є обов'язковим. Сценарії можуть виконуватися безпосередньо з PowerShell або командного рядка Windows після встановлення Python і PyAV.

## 6. PyCharm Community Edition (необов'язково)

Під час розроблення та тестування сценаріїв використовувався PyCharm Community Edition. Він не потрібен для виконання сценаріїв, але може бути зручним для редагування коду, контролю процесу виконання та перегляду повідомлень про помилки.

Якщо сценарій запускається з PyCharm, переконайтеся, що в налаштуваннях проєкту вибрано той інтерпретатор Python, у який встановлено пакет `av`.

## 7. Типова помилка

Якщо під час запуску з'являється повідомлення:

```text
ModuleNotFoundError: No module named 'av'
```

встановіть PyAV саме для того інтерпретатора Python, яким запускається сценарій:

```powershell
py -m pip install av
```
