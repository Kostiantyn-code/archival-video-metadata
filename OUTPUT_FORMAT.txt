ФОРМАТ ВИХІДНИХ ДАНИХ

Сценарії формують текстові табличні дані для подальшого використання в електронних таблицях, зокрема Microsoft Excel.

РОЗДІЛЬНИКИ

Роздільник полів: крапка з комою (;).
Десятковий роздільник у значенні розміру файла: кома.

Приклад рядка:
0001.mp4;1920x1080;03:27;31,30;A1B2C3D4...

Такий формат зручний для типових українських регіональних налаштувань Windows та Microsoft Excel, де кома використовується як десятковий роздільник.

ПОРЯДОК ПОЛІВ

1. назва файла або шлях до файла;
2. роздільна здатність відео (ширинаxвисота);
3. тривалість;
4. розмір файла;
5. SHA-256.

Поточні сценарії не додають рядка із заголовками колонок.

РЕКОМЕНДОВАНИЙ PYTHON-СЦЕНАРІЙ

python/archival_video_metadata.py:
- записує лише назву файла без повного шляху;
- роздільність: наприклад 1920x1080;
- тривалість округлюється до найближчої цілої секунди;
- до однієї години використовується формат MM:SS, для довших записів — HH:MM:SS;
- розмір обчислюється як кількість байтів / (1024 x 1024) і подається з двома знаками після коми, наприклад 31,30;
- SHA-256 подається у верхньому регістрі;
- CSV записується у UTF-8 with BOM (utf-8-sig).

PYTHON-СЦЕНАРІЙ, СУМІСНИЙ ІЗ POWERSHELL

python/powershell_compatible.py:
- записує лише назву файла;
- тривалість подає у форматі MM:SS із відкиданням дробової частини секунди;
- розмір округлює до двох знаків і використовує десяткову кому;
- SHA-256 подає у верхньому регістрі;
- використовує роздільник ; та кодування UTF-8 with BOM (utf-8-sig).

POWERSHELL-СЦЕНАРІЙ

powershell/resolution3.ps1:
- у першому полі записує повний шлях до файла;
- тривалість подає у форматі MM:SS;
- розмір округлює до двох знаків і використовує десяткову кому;
- SHA-256 обчислює командою Get-FileHash;
- поля розділяє крапкою з комою (;).

PowerShell-сценарій використовує Out-File -Encoding utf8. У Windows PowerShell 5.1 це UTF-8 із BOM; у сучасних версіях PowerShell значення utf8 означає UTF-8 без BOM.

ВІДКРИТТЯ В MICROSOFT EXCEL

За типових українських регіональних налаштувань файл із роздільником ; зазвичай коректно розділяється на колонки.

Якщо Excel не розпізнав структуру або кодування автоматично, скористайтеся:
Data -> From Text/CSV
і виберіть UTF-8 та роздільник ;.

Використання крапки з комою як роздільника пов'язане з регіональними налаштуваннями, а не з розкладкою клавіатури.
