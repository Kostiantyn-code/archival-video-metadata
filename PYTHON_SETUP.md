# Запуск Python-сценаріїв у Windows

Ця інструкція стосується Python-сценаріїв у каталозі `python/`:

- `python/archival_video_metadata.py` — рекомендована версія;
- `python/powershell_compatible.py` — версія, сумісна за форматом результату з первинним PowerShell-сценарієм.

## Що потрібно встановити самостійно

Для запуску Python-сценаріїв у Windows необхідно самостійно встановити:

1. **Python** — інтерпретатор, який виконує сценарій. Актуальна версія PyAV 18.0.0 потребує Python 3.11 або новішого.
2. **PyAV** (`av`) — сторонню Python-бібліотеку для роботи з мультимедійними контейнерами та відеопотоками.

Інші модулі, які імпортують сценарії (`csv`, `hashlib`, `math`, `pathlib`), входять до стандартної бібліотеки Python і окремого встановлення не потребують.

## Чи потрібно окремо встановлювати FFmpeg?

**Ні, для звичайного запуску Python-сценаріїв у Windows окреме встановлення FFmpeg не потрібне.** Офіційні бінарні пакети PyAV для Windows, які встановлюються через `pip`, постачаються пов'язаними з бібліотеками FFmpeg.

Python-сценарії цього репозитарію не запускають `ffmpeg.exe` або `ffprobe.exe` як окремі програми. Вони звертаються до мультимедійних функцій через бібліотеку PyAV.

Окреме встановлення FFmpeg може знадобитися лише для нестандартних конфігурацій, наприклад під час самостійного складання PyAV із вихідного коду.

## 1. Встановлення Python

Встановіть актуальну версію Python для Windows.

Після встановлення перевірте доступність Python у PowerShell або командному рядку:

```powershell
py --version
```

Якщо команда `py` недоступна, перевірте:

```powershell
python --version
```

## 2. Встановлення PyAV

Найпростіший спосіб — встановити залежності з файла `requirements.txt` у корені репозитарію:

```powershell
py -m pip install -r requirements.txt
```

або встановити PyAV безпосередньо:

```powershell
py -m pip install av
```

За потреби перед цим можна оновити `pip`:

```powershell
py -m pip install --upgrade pip
```

## 3. Перевірка встановлення PyAV

```powershell
py -c "import av; print(av.__version__)"
```

Якщо команда виводить номер версії без повідомлення про помилку, PyAV встановлено коректно.

## 4. Налаштування шляхів у сценарії

Перед запуском відкрийте потрібний файл у каталозі `python/` і змініть шляхи відповідно до вашої системи.

У рекомендованому сценарії `python/archival_video_metadata.py` це параметри:

```python
INPUT_DIR = Path(r"D:\temp\2026")
OUTPUT_FILE = Path(r"D:\temp\resolution-python-recommended.csv")
ERROR_FILE = Path(r"D:\temp\resolution-python-errors.txt")
```

- `INPUT_DIR` — директорія з відеофайлами; піддиректорії опрацьовуються рекурсивно.
- `OUTPUT_FILE` — CSV-файл із результатами.
- `ERROR_FILE` — текстовий файл із повідомленнями про помилки; створюється лише за наявності помилок.

## 5. Запуск

Перейдіть у каталог репозитарію та виконайте рекомендований сценарій:

```powershell
py python\archival_video_metadata.py
```

Для версії, сумісної з первинним PowerShell-сценарієм:

```powershell
py python\powershell_compatible.py
```

## 6. Формат вихідного CSV

Python-сценарії використовують крапку з комою (`;`) як роздільник полів і десяткову кому для розміру файла. Рекомендований сценарій записує CSV у кодуванні **UTF-8 with BOM** (`utf-8-sig`), що зручно для відкриття файлів у Microsoft Excel за типових українських регіональних налаштувань.

Докладний опис порядку полів, відмінностей між версіями сценаріїв, формату тривалості, кодування та імпорту в Excel наведено в **[OUTPUT_FORMAT.md](OUTPUT_FORMAT.md)**.

## 7. PyCharm Community Edition (необов'язково)

**PyCharm Community Edition не є обов'язковим компонентом.** Під час розроблення та тестування він використовувався як зручне середовище для редагування коду, запуску сценаріїв, візуального контролю процесу виконання та перегляду повідомлень про помилки.

Python-сценарії можна запускати без PyCharm безпосередньо з PowerShell або командного рядка Windows.

Якщо сценарій запускається з PyCharm, переконайтеся, що в налаштуваннях проєкту вибрано той інтерпретатор Python, у який встановлено пакет `av`.

## 8. Типова помилка

Якщо під час запуску з'являється повідомлення:

```text
ModuleNotFoundError: No module named 'av'
```

встановіть PyAV саме для того інтерпретатора Python, яким запускається сценарій:

```powershell
py -m pip install av
```
