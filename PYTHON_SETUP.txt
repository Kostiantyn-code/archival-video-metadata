ЗАПУСК PYTHON-СЦЕНАРІЇВ У WINDOWS

Ця інструкція стосується сценаріїв:
- python/archival_video_metadata.py — рекомендована версія;
- python/powershell_compatible.py — версія, сумісна за форматом результату з первинним PowerShell-сценарієм.

ЩО ПОТРІБНО ВСТАНОВИТИ

1. Python — інтерпретатор для виконання сценаріїв.
2. PyAV (пакет av) — стороння бібліотека Python для роботи з мультимедійними контейнерами та відеопотоками.

Модулі csv, hashlib, math і pathlib входять до стандартної бібліотеки Python і окремого встановлення не потребують.

Для звичайного запуску Python-сценаріїв у Windows окремо встановлювати FFmpeg не потрібно: бінарні пакети PyAV для Windows постачаються пов'язаними з бібліотеками FFmpeg. Сценарії не запускають ffmpeg.exe або ffprobe.exe як окремі програми.

ВСТАНОВЛЕННЯ

Перевірка Python:
py --version

Якщо команда py недоступна:
python --version

Встановлення залежностей із кореня репозитарію:
py -m pip install -r requirements.txt

Або безпосередньо:
py -m pip install av

За потреби оновлення pip:
py -m pip install --upgrade pip

Перевірка PyAV:
py -c "import av; print(av.__version__)"

НАЛАШТУВАННЯ ШЛЯХІВ

У рекомендованому сценарії python/archival_video_metadata.py змініть:
INPUT_DIR = Path(r"D:\temp\2026")
OUTPUT_FILE = Path(r"D:\temp\resolution-python-recommended.csv")
ERROR_FILE = Path(r"D:\temp\resolution-python-errors.txt")

INPUT_DIR — директорія з відеофайлами; піддиректорії опрацьовуються рекурсивно.
OUTPUT_FILE — CSV-файл із результатами.
ERROR_FILE — текстовий файл із повідомленнями про помилки; створюється лише за наявності помилок.

ЗАПУСК

Рекомендований сценарій:
py python\archival_video_metadata.py

Сумісна версія:
py python\powershell_compatible.py

PYCHARM COMMUNITY EDITION

PyCharm Community Edition не є обов'язковим. Під час розроблення та тестування він використовувався для редагування коду, запуску сценаріїв, візуального контролю виконання та перегляду повідомлень про помилки. Сценарії можна запускати без PyCharm із PowerShell або командного рядка Windows.

Якщо сценарій запускається з PyCharm, переконайтеся, що вибрано той інтерпретатор Python, у який встановлено пакет av.

ТИПОВА ПОМИЛКА

ModuleNotFoundError: No module named 'av'

У такому разі виконайте:
py -m pip install av

Формат вихідних даних докладно описано у файлі OUTPUT_FORMAT.txt.
