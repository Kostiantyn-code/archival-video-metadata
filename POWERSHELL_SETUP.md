# Запуск PowerShell-сценарію у Windows

Ця інструкція стосується сценарію:

`powershell/resolution3.ps1`

Сценарій рекурсивно опрацьовує відеофайли, визначає їх роздільність і тривалість за допомогою `ffprobe`, обчислює розмір файла та SHA-256 і записує результат у CSV-файл.

## Що потрібно встановити самостійно

Для роботи сценарію потрібні:

1. **PowerShell** — середовище виконання сценарію. У Windows можна використовувати Windows PowerShell або сучасний PowerShell.
2. **FFmpeg** — окремий пакет мультимедійних утиліт. Сценарій безпосередньо запускає `ffprobe.exe`, який входить до складу FFmpeg.

Python, PyAV і PyCharm для PowerShell-сценарію не потрібні.

## 1. Встановлення FFmpeg

Завантажте збірку FFmpeg для Windows і розпакуйте її у зручний каталог.

Поточний сценарій очікує `ffprobe.exe` за шляхом:

```text
C:\Tools\ffmpeg\bin\ffprobe.exe
```

Можна зробити одним із двох способів:

- розмістити FFmpeg так, щоб `ffprobe.exe` знаходився саме за цим шляхом;
- або відкрити `powershell/resolution3.ps1` і змінити шлях у рядку:

```powershell
$info = & "c:\Tools\ffmpeg\bin\ffprobe.exe" ...
```

на фактичний шлях до вашого `ffprobe.exe`.

## 2. Перевірка ffprobe

У PowerShell виконайте:

```powershell
& "C:\Tools\ffmpeg\bin\ffprobe.exe" -version
```

Якщо виводиться інформація про версію без повідомлення про помилку, `ffprobe` доступний.

Якщо FFmpeg встановлено в іншому каталозі, використайте відповідний шлях.

## 3. Налаштування шляхів у сценарії

Перед запуском змініть у `powershell/resolution3.ps1` шляхи відповідно до вашої системи.

Вхідна директорія:

```powershell
$mainDirectory = "d:\temp\2026"
```

Файл результату:

```powershell
$outputFilePath = "d:\temp\resolution.csv"
```

Сценарій рекурсивно шукає файли таких типів:

```text
*.mp4, *.mov, *.avi, *.mpg
```

## 4. Запуск сценарію

Перейдіть у каталог репозитарію та виконайте:

```powershell
.\powershell\resolution3.ps1
```

Після завершення сценарій створить CSV-файл за шляхом, указаним у `$outputFilePath`.

## 5. Якщо Windows блокує запуск сценарію

Спочатку перевірте поточну політику виконання:

```powershell
Get-ExecutionPolicy
```

Якщо запуск локального сценарію заборонено, для поточного облікового запису можна дозволити виконання локальних сценаріїв командою:

```powershell
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
```

Якщо файл було завантажено з Інтернету і Windows позначила його як зовнішній, іноді достатньо розблокувати лише цей файл:

```powershell
Unblock-File .\powershell\resolution3.ps1
```

Після цього повторіть запуск сценарію.

## 6. Які засоби використовує сценарій

Для отримання технічних характеристик відео використовується зовнішня утиліта **ffprobe** зі складу FFmpeg.

Інші операції виконуються штатними засобами PowerShell:

- `Get-ChildItem` — пошук файлів;
- `Get-Item` — визначення розміру файла;
- `Get-FileHash -Algorithm SHA256` — обчислення SHA-256;
- `Out-File` — запис результатів у файл.

Отже, для PowerShell-версії єдина стороння програма, яку потрібно встановити окремо, — **FFmpeg (ffprobe)**.
